# ajmccall/homebrew-tap

Homebrew tap for my macOS tools.

```sh
brew install --cask ajmccall/tap/talkie
xattr -dr com.apple.quarantine /Applications/Talkie.app   # until Talkie is notarised
```

| Cask | What it is |
|---|---|
| `talkie` | Local push-to-talk dictation: hold Fn, speak, text is pasted. https://github.com/ajmccall/talkie |
